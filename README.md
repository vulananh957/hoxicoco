# Hoxicoco

Ứng dụng web sử dụng Node.js và Gemini API.

## Chạy dự án local

**Yêu cầu:** Node.js

1. Cài đặt các dependencies:
   `npm install`
2. Thêm API key Gemini vào file `.env.local`:
   `GEMINI_API_KEY=your_gemini_api_key`
3. Khởi động ứng dụng:
   `npm run dev`
